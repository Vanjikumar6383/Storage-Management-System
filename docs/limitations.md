# Project Scope & System Limitations

This document outlines the current scope, design boundaries, and technical limitations of the Storage Lifecycle Optimizer platform.

---

## 1. Cloud Provider Support Scope
- **Supported Providers**: `LOCAL_S3_COMPATIBLE` (Demo Mode) and `AWS_S3` (Production AWS Mode).
- **Unsupported Providers**: Azure Blob Storage and Google Cloud Storage (GCS) interfaces are defined in enums and factory abstractions, but concrete cloud SDK adapters for Azure and GCP are not yet implemented. Attempts to instantiate them raise `UnsupportedProviderError`.

---

## 2. Safety & Physical Delete Safeguards
- **Simulation-Only Deletion**: Physical object payload deletion is explicitly disabled across all execution paths. Recommendations of type `DELETE_CANDIDATE` return status `DELETE_SIMULATION_SUCCESS` and record audit log events without executing physical payload deletion commands.

---

## 3. Cost & Savings Calculations
- **Pricing Model**: Cost calculations use standardized public pricing tiers (e.g. AWS S3 Standard: $0.023/GB, Infrequent Access: $0.0125/GB, Archive: $0.004/GB). Actual customer AWS bills may vary based on Enterprise Discount Programs (EDP), regional pricing variations, dynamic request volume charges, and egress transfer fees.

---

## 4. Benchmark Dataset Scope
- **Synthetic Data**: Benchmark datasets generated by `IndustryDatasetGenerator` are synthetic distributions designed to evaluate short-lived development environments. They do not represent real customer personal or proprietary data.
